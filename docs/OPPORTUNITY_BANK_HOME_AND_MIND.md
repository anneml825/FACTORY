## Two design rules if anything here gets built

**The ⚠ rule.** Every mental-health item ships as a place to record and organise. No scoring
against clinical cut-offs, no interpretation of what a pattern means, no treatment suggestion,
no crisis handling. If a feature would require that, cut the feature — the established pattern
of excluding rather than disclaiming.

**The free-substitute test.** Anything whose core is a single well-known formula loses to a free
web calculator. Most of the list above survives that test because the value is persistent,
multi-entity structure rather than one computation.
