## Opportunity signature (fixed before the run)

An opportunity is a query where **demand is proven but incumbents are weak**:
- demand proven: top plugin has ≥ 1,000 active installs
- not dominated: top plugin ≤ 200,000 active installs
- ≥1 weakness: unmaintained ≥ 18 months, rated < 80/100, support resolution < 50%, or ≤3 competitors

**A large, well-maintained, well-rated incumbent scores zero.** A solved problem is
not an opportunity, however big its install base — that is the misreading this rule exists to prevent.
